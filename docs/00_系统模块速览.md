## 模块 ID 说明

- 模块 ID 是文档二与结果展示网站 URL 中的稳定标识(如 `?module=person_align`)；中文标题可改，ID 不变。
- 标注（历史兼容）的模块属于旧 CHR 链或兼容支路，默认不在主线讲解路线中；标注（外部）的模块由仓库外工具产出结果。
- `lifecycle=optional` 的模块按运行配置决定是否执行，不代表系统必然产出对应产物。
- 「结果文件与服务」上表按文档二基线列出旧展示器 `asset_viewer/`；其新实现位于 `result_viewer/`(后端 `backend/` + 前端 `frontend/`)，设计依据见 [03_结果展示网站设计.md](03_结果展示网站设计.md)。
